Tsubame

Tsubame est un client natif pour le bureau GNOME, qui se connecte aux comptes du protocole AT (Bluesky).

Cette adresse identifie l'application auprès de votre serveur quand vous vous connectez. Tsubame ne voit jamais votre mot de passe : vous vous connectez sur la page de votre serveur, qui lui accorde ensuite un accès que vous pouvez retirer à tout moment depuis les réglages de votre compte.

Code source et documentation : github.com/DocteurScience/Tsubame (licence GPL-3.0).
